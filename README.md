# Мутация

Мобильная хоррор-головоломка со слиянием. Бросайте существ в банку с формалином: два одинаковых сливаются в следующую форму. Не дайте банке переполниться.

## Как играть

- Ведите пальцем по банке и отпустите, чтобы бросить существо. Мышью: клик.
- Клавиатура: стрелки двигают прицел, пробел бросает, Esc открывает меню.
- Игра заканчивается, если кто-то задержится выше линии «КРЫШКА» дольше ~2,5 секунды.
- Умения, по одному разу за партию: **Тряска**, **Удалить** (затем коснитесь существа), **Заменить** текущий образец.

## Цепочка мутаций (14 форм)

Капля → Спора → Слизень → Личинка → Глаз → Пиявка → Зубастик → Многоглаз → Мозгляк → Сгусток → Пасть → Тварь → Кокон → Матка

Две Матки уничтожают друг друга и дают +500. Пока Матка в банке, она рожает мусор. Нажмите на открытую форму в реестре, чтобы прочитать запись из журнала лаборанта.

## Аномалии

| Аномалия | Что делает |
|---|---|
| Гниль | Не сливается. Растворяется, если рядом рождается Глаз или крупнее (+10) |
| Паразит | Присасывается и ворует 3 очка каждые ~1,4 с. Раздавите слиянием рядом — вернёт украденное вдвое +15 |
| Матка паразитов | Каждые 9 с рожает паразита. Раздавите слиянием рядом: +60 |
| Мутаген | Поднимает первое задетое существо на уровень выше |
| Кислота | Растворяет Капель и Спор вокруг (+2 за каждую) |
| Зеркало | Становится копией первого задетого существа |
| Магнит | 8 секунд стягивает одинаковых существ друг к другу |

## Банки

Обычная, вязкая (всё падает медленно), узкая колба, трясущаяся (каждые 30 с), тёмная (видно только под фонариком). В классике банку выбирают в меню, в дневном забеге она меняется по дням недели. Иногда в любой банке гаснет свет, и видны только глаза.

## Режимы и прогресс

- **Классика** со случайными образцами.
- **Падение**: как в тетрисе — мутант сам опускается сверху, вы ведёте его пальцем влево-вправо, смахиванием или кнопкой «Вниз» сбрасываете быстрее. Каждые 500 очков уровень и скорость падения растут.
- **Дневной забег**: у всех одинаковые образцы и банка на текущие сутки (UTC).
- **Вызов**: ссылка `#vyzov-<seed>-<очки>[-<банка>]` даёт другу ту же партию и цель.
- **Серия дней**: награды за 3, 7 и 30 дней — изумрудный, кровавый и чёрный формалин.
- **Три задания дня**, одинаковые у всех, и 25 достижений.
- **Рекорды дня и недели.** Очки недели — сумма лучших дневных забегов.
- **Поделиться**: картинка 1080×1920 для сторис и вертикальные видеоклипы последних секунд (скример, две Матки, финал).

## Где хранятся рекорды

- Версия на claude.ai использует общую базу артефакта.
- Версия на GitHub Pages использует таблицу `mutaciya_scores` в Supabase. Читать её может любой. Писать можно только через функции `mutaciya_submit` и `mutaciya_rename`: они проверяют секретный ключ игрока, который хранится в его браузере, и границы значений. Защиты от подделки счёта через прямой вызов функции нет — для казуальной таблицы этого достаточно.
- Без сети игра работает: результаты сохраняются на устройстве.

## Запуск

Откройте `index.html` в браузере. Сборка не нужна: все файлы уже в репозитории, внешние сервисы игре не нужны.

## Структура

- `index.html` — готовая игра для GitHub Pages. Собирается скриптом, руками не правится.
- `src/game.html` — исходник страницы. Эта же версия публикуется на claude.ai.
- `build.py` — собирает `index.html` из исходника и подменяет внешние ресурсы локальными: `python3 build.py`.
- `src/sw.template.js` — шаблон service worker; `build.py` подставляет версию и список файлов в `sw.js`.
- `manifest.webmanifest`, `icons/` — установка игры на главный экран.
- `vendor/` — физика [Matter.js](https://brm.io/matter-js/) 0.19.0 (MIT).
- `fonts/` — шрифты Rubik Distressed, Rubik Wet Paint, Rubik Glitch, IBM Plex Sans и IBM Plex Mono (SIL OFL), кириллица и латиница.
- `licenses/` — лицензии библиотеки и шрифтов.

## GitHub Pages

Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`. На телефоне игру можно добавить на главный экран, она откроется во весь экран.
