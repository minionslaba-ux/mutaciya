# Мутация

Браузерная хоррор-головоломка со слиянием. Бросай существ в банку с формалином: два одинаковых сливаются в следующую форму. Не дай банке переполниться.

## Как играть

- Клик или касание: бросить существо.
- Стрелки двигают прицел, пробел бросает.
- Игра заканчивается, если кто-то задержится выше линии «КРЫШКА» дольше ~2,5 секунды.

## Цепочка мутаций

Капля → Спора → Слизень → Личинка → Глаз → Пиявка → Зубастик → Многоглаз → Сгусток → Тварь → Матка

Две Матки уничтожают друг друга и дают +500 очков.

## Запуск

Открой `index.html` в браузере. Сборка не нужна. Физика: [Matter.js](https://brm.io/matter-js/) 0.19.0 с cdnjs, все существа рисуются кодом на Canvas.

## Публикация через GitHub Pages

Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
