# Мутация

Мобильная хоррор-головоломка со слиянием. Бросайте существ в банку с формалином: два одинаковых сливаются в следующую форму. Не дайте банке переполниться.

## Как играть

- Ведите пальцем по банке и отпустите, чтобы бросить существо. Мышью: клик.
- Клавиатура: стрелки двигают прицел, пробел бросает, Esc открывает меню.
- Игра заканчивается, если кто-то задержится выше линии «КРЫШКА» дольше ~2,5 секунды.

## Цепочка мутаций

Капля → Спора → Слизень → Личинка → Глаз → Пиявка → Зубастик → Многоглаз → Сгусток → Тварь → Матка

Две Матки уничтожают друг друга и дают +500 очков.

## Особенности

- **Скримеры.** Когда вы впервые выводите новую форму (начиная с Личинки), она на долю секунды бросается на экран со звуком и вибрацией. Отключаются в меню; при «уменьшении движения» в системе выключены по умолчанию.
- **Аномалии.** Появляются в очереди не сразу и не подряд:
  - **Гниль** не сливается и только занимает место. Растворяется, если рядом рождается Глаз или форма крупнее (+10 очков).
  - **Паразит** ползёт к ближайшему существу, присасывается и каждые ~1,4 с ворует 3 очка. Если рядом с ним произойдёт слияние, он раздавлен и возвращает украденное вдвое (+15 сверху).
  - **Мутаген** превращает первое существо, которого коснётся, в следующую форму.
- **Дневной забег.** У всех игроков одна и та же последовательность образцов на текущие сутки (по UTC).
- **Рекорды дня и недели.** В таблицу дня идёт лучший результат дня. Очки недели — сумма лучших результатов каждого дневного забега с понедельника по воскресенье.
- **Поделиться результатом.** После игры кнопка собирает картинку 1080×1920 для сторис: счёт, режим, снимок банки, высшая форма и прогресс реестра. На телефоне открывается системное меню «Поделиться», на компьютере картинка сохраняется файлом.
- **Реестр мутаций.** Неоткрытые формы скрыты, пока вы их не выведете.

## Таблица рекордов

Общие таблицы дня и недели работают в версии игры, опубликованной на claude.ai (там есть общая база данных). В этой статической версии хранятся только ваши результаты на этом устройстве.

## Запуск

Откройте `index.html` в браузере. Сборка не нужна: все файлы уже в репозитории, внешние сервисы игре не нужны.

## Структура

- `index.html` — готовая игра для GitHub Pages. Собирается скриптом, руками не правится.
- `src/game.html` — исходник страницы. Эта же версия публикуется на claude.ai.
- `build.py` — собирает `index.html` из исходника и подменяет внешние ресурсы локальными: `python3 build.py`.
- `vendor/` — физика [Matter.js](https://brm.io/matter-js/) 0.19.0 (MIT).
- `fonts/` — шрифты Russo One, IBM Plex Sans и IBM Plex Mono (SIL OFL), кириллица и латиница.
- `licenses/` — лицензии библиотеки и шрифтов.

## GitHub Pages

Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`. На телефоне игру можно добавить на главный экран, она откроется во весь экран.
