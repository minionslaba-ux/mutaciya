# Каталог миссий «Мутации»

Правила — скилл `.claude/skills/raznoobraznye-missii`. Проверка: `python3 .claude/skills/raznoobraznye-missii/scripts/check_missions.py docs/missii-katalog.md`.

«Мутация» — головоломка в банке без карты, поэтому X/Z пустые. Типы из скилла переложены на жанр так:
- **вождение** → мастерство управления: точный бросок, работа пальцем/мышью под помехой;
- **бой** → активная борьба с угрозой касаниями (поймать, раздавить, сжечь);
- **спокойная** → без давления и таймера, «накопить/вырастить»;
- **головоломка** → планирование укладки и порядка слияний.

«Главы»: первая смена новичка (цели подряд), испытания (5 уровней), пул заданий дня (3 в день из 13), ЧП во время смены (события-миссии).
Длина — минуты (≈).
